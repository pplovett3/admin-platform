# 中职院校“自动化产线”专业虚拟仿真三维课件与AI教学平台建设方案（示例）

> 适用对象：中等职业学校【自动化产线/机电一体化/工业机器人/电气自动化】相关专业  
> 交付形态：私有化部署（内网纯离线为主），可选公网/专网访问方案  
> 本方案基于《市场资料/建设方案模板.md》深化而来，可直接用于预算申报/立项汇报/招采材料编制。

---

## 1. 项目背景与建设必要性
### 1.1 专业建设背景
自动化产线专业面向制造业现场岗位（装配、检测、上下料、物流搬运、产线运维与故障诊断等），教学过程高度依赖“设备结构认知 + 工艺流程理解 + 控制逻辑训练 + 安全规范”。

在传统实训条件下，普遍存在：
- **设备投入高、更新快**：产线设备昂贵且维护成本高，难以覆盖所有典型工位与故障情境。
- **可视化与可重复训练不足**：复杂机构与电气控制难以在课堂中反复拆解演示。
- **教学资源难沉淀复用**：模型资产、项目成果、课件脚本散落，老师制作门槛高。
- **教学效果难量化**：缺少学习过程数据与测评闭环，难支撑“岗课赛证”一体化。

### 1.2 建设必要性
建设“**三维课件生产 + AI讲课生成 + 发布分享 + 多端播放（Web/Unity/VR）+ 测评数据回流**”平台，能够将产线专业的典型场景与设备认知、操作流程、故障诊断等内容标准化、结构化与可复用化，形成“可交付、可验收、可持续迭代”的数字资源体系。

## 2. 建设目标
### 2.1 总体目标
面向【自动化产线】专业建设一体化平台，实现：
1) 老师0代码制作三维课件（结构树/标注/动画步骤/时间线）  
2) AI生成讲课脚本（文字+图片+三维动作+配音）并可编辑  
3) 一键发布形成可分享的学习内容（Web/Unity/VR一致播放）  
4) 配套题库测评与学习统计，支撑教学评价与“岗课赛证”要求  
5) （可选）PICO元宇宙教学大厅支持多人授课、同步演示与白板协作

### 2.2 可量化指标（建议，按项目填数）
- 资源建设：完成标杆三维课件【X】个、AI讲课课程【Y】个、题库【Z】套。
- 效率指标：单门“标准体量”课件从模型到发布≤【X】小时。
- 性能指标：Web端三维浏览目标60FPS；VR端目标90FPS（按模型体量分档）。
- 并发指标：支持【N】用户并发访问（含资源下载/播放）。

## 3. 建设范围与交付内容（按三件套拆包）

### 3.1 A包：AI智能3D内容创作工具（Web，老师端）
#### 3.1.1 三维课件编辑（Courseware）
- 模型导入/加载：支持glTF/GLB等主流格式（按项目可包含FBX/OBJ转换流程）。
- 结构树：层级展示、搜索定位、折叠展开；对象选中/高亮/显隐/隔离/对焦。
- 标注：创建标注（标题+简介），点击联动（对焦/高亮）；支持批量整理与导入导出（按项目启用）。
- 动画与步骤：支持多动画管理；步骤（step）定义；时间线编辑（相机/显隐/高亮/变换轨道按项目启用）；预览播放。
- 保存与版本：自动保存、版本管理、导入导出（`courseware.json`）保证跨端一致。
- 场景增强（可选）：支持“高斯泼溅（Gaussian Splatting）”作为背景/环境增强，提升沉浸与真实感。

**【建议配图3：三维课件编辑器三栏界面截图】**

#### 3.1.2 AI智能整理（面向“产线设备模型结构复杂”的痛点）
- AI自动识别并重命名部件（传感器、气缸、伺服、电机、输送带、机械手、工装夹具等）。
- AI结构树分组整理（按工位/机构/电气/气动/安全/输送等逻辑分组）。
- 逐对象识别模式：提升复杂模型识别准确率；结果预览对比与一键应用。
- AI生成标注简介：按教学口径输出50-150字简介，老师可编辑。

- 一键生成大纲与脚本：输出`talk / image.explain / scene.action`三类段落。

- 三维动作向导：从结构树/标注/动画中选择目标（相机对焦、显隐、高亮、动画片段播放、标注显示）。
- TTS配音：多供应商音色选择与试听；发布时批量配音并生成音频清单。
- 预览：浏览器端联动播放（音频+字幕/文本+图片+三维动作）。

## 4. 总体架构与部署形态（私有化交付）

### 4.1 架构说明（参考）
- Web前端：管理后台、三维课件编辑器、AI课程编辑器、学习播放页、统计与报表。
- 后端服务：鉴权、课件/课程/发布、AI服务编排（LLM/图片检索/TTS）、测评与统计。
- 数据库：MongoDB（或按学校规范替换）。
- 文件存储：标准服务器本地磁盘/挂载存储为默认；可选对象存储（MinIO等）以提升大资源管理能力。
- Unity/PICO客户端：元宇宙教学大厅应用（支持离线缓存与断点续传按项目启用）。

**【建议配图12：总体架构图】**  
- 图名建议：`图12 总体架构：Web平台 + 后端服务 + 存储 + Unity/PICO客户端`  
- 配图内容：组件框图，体现“内网离线默认，公网可选”。

### 4.2 部署模式（满足学校信息化要求）
#### 模式A：内网纯离线（默认推荐）
- 访问范围：学校内网/专网访问，不依赖公网域名。
- HTTPS：可选（内网CA/自签证书），或由内网反向代理统一终止TLS。
- 外联限制：默认不访问公网；AI能力支持：
  - 离线可用：仅使用本地素材库/本地TTS/本地大模型（按学校条件选型）。
  - 受限可用：经审批后白名单出网访问指定AI服务（LLM/TTS/检索），并记录审计日志。

#### 模式B：公网/专线可访问（可选）
- 访问范围：公网域名或教育网/专线；支持校外访问与对外展示。
- HTTPS：强制启用（域名证书），建议Nginx/网关反向代理统一接入。
- 安全：WAF/限流（可选）、最小暴露端口、可选统一认证（CAS等）。

#### 端口与网络建议（便于网信/信息办审核）
- 推荐对外仅暴露：`80/443`（由反向代理统一接入）。
- 数据库与存储服务不对公网暴露，仅允许应用服务器访问。

## 5. 实施计划与里程碑（建议：12周交付）
### 阶段1：需求调研与方案深化（第1-2周）
- 专业课程群梳理：对标“岗课赛证”，明确课程清单与能力点。
- 资源盘点：现有模型/图纸/工艺文件/视频/PDF等。
- 输出：《需求确认单》《深化设计》《资源清单》《验收条款清单（初稿）》。

### 阶段2：平台部署与基础功能交付（第3-5周）
- 私有化部署（内网离线默认），完成账号/权限/存储配置。
- 三维课件编辑器与AI课程编辑器可用；发布与播放链路跑通。

### 阶段3：标杆资源建设（第6-10周）
建议围绕“自动化产线典型工位”建设标杆课件/课程（支持校内网页只读发布，便于校内教学与验收）：
- 标杆三维课件【X】个（示例方向）：
  1) 产线总体结构与物流路径（输送线、分拣、缓存、上下料）
  2) PLC与I/O：传感器、执行器、气动元件与接线逻辑
  3) 工位节拍与动作序列：上料→定位→加工→检测→下料
  4) 工业机器人上下料（或机械手）与安全互锁
  5) 典型故障诊断：传感器异常、气压不足、急停触发、夹具不到位等
- AI讲课课程【Y】个（基于上述课件生成并人工修订）
- 题库【Z】套：理论题+互动识别题（关键部件识别、流程顺序、故障原因定位等）
- 完成Web与Unity/VR一致播放联测（如启用C包）。

### 阶段4：培训、试运行与验收（第11-12周）
- 管理员/教师培训；试运行问题闭环。
- 输出：《验收报告》《运维手册》《培训材料》《部署包/镜像/配置》。

## 9. 风险与对策（自动化产线专业常见）
- 模型结构复杂命名混乱 → AI智能整理（逐对象识别）+ 人工审核 + 形成专业部件命名规范。
- 资源体量大导致加载慢 → 压缩/分层加载/缓存；内网对象存储（可选）；客户端离线缓存。
- AI外联受限（内网离线） → 本地素材库/离线配音策略；或审批白名单出网并做审计。
