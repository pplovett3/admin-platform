## 1. A包：AI智能3D内容创作工具（Web，老师端）

### 1.1 账号/权限（老师端）
- [ ] 支持教师账号登录（内网环境可用）。
- [ ] 角色权限符合约定：平台管理员/学校管理员/教师/学生（按项目启用）。
- [ ] 资源可见域符合约定：个人/校内/平台公共/公开发布（按项目启用）。

### 1.2 三维课件编辑（Courseware）
- [ ] 支持新建课件，并关联/选择模型资源（个人/公共资源）。
- [ ] 支持结构树展示、搜索、折叠展开。
- [ ] 支持对象选中、高亮、显隐、隔离、对焦定位。
- [ ] 支持标注创建/编辑/删除（标题+简介），标注点击可联动对焦与高亮。
- [ ] 支持动画管理（新建/编辑/删除），支持步骤（step）管理与按步骤播放。
- [ ] 支持时间线编辑（至少包含：相机关键帧、显隐/高亮；变换轨道按项目启用）。
- [ ] 支持保存后重新打开一致（标注/动画/设置不丢失）。
- [ ] 支持导出课件包（`courseware.json`）并能重新导入恢复一致（如启用导入）。

### 1.3 AI智能整理（模型结构/标注增强）
- [ ] 支持“AI智能整理”入口与执行进度提示。
- [ ] 支持AI对结构树进行**重命名/分组整理**，并提供“整理前/整理后”预览对比。
- [ ] 支持“逐对象识别”模式，提高识别准确率（如启用）。
- [ ] 支持一键应用AI整理结果到结构树。
- [ ] 支持AI生成标注简介（50-150字，教学口径），并可人工修改后保存。

### 1.4 AI课程编辑（AICourse：大纲/脚本/图片/配音）
- [ ] 支持新建AI课程并关联课件（`coursewareId`）。
- [ ] 支持填写基础信息（主题/受众/时长/语言/音色等）。
- [ ] 支持一键生成课程大纲/脚本（含 talk / image.explain / scene.action）。
- [ ] 支持图片检索与候选选择（内网离线模式下可切换为本地素材库/不启用检索）。
- [ ] 支持TTS试听（至少一种供应商可用），试听结果可播放。
- [ ] 支持课程预览播放（音频+字幕/文本+三维联动）。
- [ ] 支持保存与版本迭代（草稿/已发布按项目启用）。

## 2. B包：发布分享与学习测评（Web，学生/公开端）

### 2.1 发布与分享
- [ ] 支持从后台发布课程，生成分享链接（URL）。
- [ ] 支持发布配置项（如：自动播放/是否公开/是否允许下载等，按项目启用）。
- [ ] 支持更新发布内容（手动更新/重新发布机制，按项目约定）。
- [ ] 支持停用/下线发布内容。

### 2.2 播放体验（公开页/校内页）
- [ ] 支持播放控制：播放/暂停、进度拖动、倍速、段落跳转。
- [ ] 支持三维联动：相机对焦、显隐/高亮、标注显示、动画片段播放（按课件数据）。
- [ ] 支持图片讲解显示与切换（如启用）。
- [ ] 支持弱网降级与预加载策略（按项目约定：预加载数量/超时策略）。

### 2.3 TTS发布（批量配音）
- [ ] 发布流程支持批量生成配音并写回课程数据（音频URL/时长等）。
- [ ] 音频资源可在内网/公网按部署模式正常访问与播放。

### 2.4 测评闭环（可选增强）
- [ ] 支持AI生成题库：理论题 + 互动识别题（互动题绑定模型部件标识）。
- [ ] 支持手动编辑题库与保存。
- [ ] 学生端支持答题提交，成绩可回传保存。
- [ ] 教师端支持查看测评记录/统计，并支持导出（如启用导出）。

## 3. C包：元宇宙教学大厅（Unity / PICO，多人授课端，可选增强）

### 3.1 房间与多人能力
- [ ] 支持创建/加入房间，房间列表展示（名称/人数/状态）。
- [ ] 支持房间密码/人数上限/时长等设置（按项目启用）。
- [ ] 支持多人Avatar显示与动作同步（目标上限：【≤50】人，按项目约定）。
- [ ] 支持多人语音通话与空间音频（按项目启用）。

### 3.2 教师控场与协作
- [ ] 教师端具备控场权限：全体静音/解除静音、禁言/踢出等（按项目启用）。
- [ ] 支持虚拟白板：教师绘制同步到学生端；支持授权学生操作（按项目启用）。
- [ ] 支持空间标记/协作标记同步（按项目启用）。

### 3.3 教学资源加载与播放
- [ ] 支持加载平台资源：3D模型/三维课件/AI+3D课件。
- [ ] 支持按步骤播放课件（标注/动画/步骤联动）。
- [ ] 支持飞屏投射与面板操控（按项目启用）。
- [ ] 支持离线缓存与断点续传（按项目启用）。

## 5. 部署与安全（私有化必验）
### 5.1 部署模式
- [ ] 模式A（内网纯离线）：在内网环境下可完整使用（不依赖公网）。
- [ ] 模式B（公网/专线）：域名与HTTPS可用，反向代理配置正确（如启用）。

### 5.2 端口与隔离
- [ ] 对外仅暴露`80/443`（推荐做法），数据库/存储不对公网暴露（按项目约定）。
- [ ] 账号权限隔离符合约定；资源访问控制有效。

### 5.3 备份与恢复
- [ ] 数据库备份策略可执行（频率：【】；保留：【】）。
- [ ] 文件存储备份策略可执行（频率：【】；保留：【】）。
- [ ] 提供恢复演练记录（可选）。

### 5.4 AI外联策略（如启用）
- [ ] 离线策略：本地素材/本地TTS/本地模型（如启用）可用。
- [ ] 白名单出网策略：仅访问指定域名/接口；具备审计记录（如启用）。
